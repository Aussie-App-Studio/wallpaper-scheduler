Wallpaper Scheduler: Time of Day

Ultra-lightweight (~0.6 MB) Windows 11 wallpaper & Light/Dark theme scheduler.

Free & Open Source No Ads No Tracking 100% Offline
Get it from Microsoft Store Download Portable (.zip) View Source on GitHub Privacy Policy

Day & Night or Custom Slots

Switch between pictures or slideshow folders at exact clock times, or automatically at sunrise and sunset.

Light & Dark Theme Sync

Optionally switch Windows 11 between Light and Dark mode whenever a slot begins.

Ordered Folder Slideshows

Preview every picture in your folder, drag thumbnails to set the exact play order, or enable shuffle.

Weekdays & Multi-Monitor

Run slots on weekdays or weekends only, and customize wallpapers per display.

Zero-Bloat Background Agent

Built in native Rust — sleeps until the next transition (~2.5 MB RAM, 0% CPU while idle) and catches up automatically on wake or unlock.

Backup & Transfer

Export your schedule to a JSON file and import it on a new PC in seconds.
